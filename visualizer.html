📖 Description

Bubble Sort repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order.

📊 Complexity Analysis
Best CaseO(n)
Average CaseO(n²)
Worst CaseO(n²)
SpaceO(1)
💻 Pseudocode
for i = 0 to n-1 for j = 0 to n-i-2 if arr[j] > arr[j+1] swap(arr[j], arr[j+1])
